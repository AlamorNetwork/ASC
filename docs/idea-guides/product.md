# دیدگاه محصول و انسان

- پیش از انتخاب فناوری، کاربر اصلی، مسئلهٔ واقعی و زمینهٔ استفاده را مشخص کن.
- فرض‌ها را با پرسش یا آزمایش قابل رد کردن بنویس؛ محبوبیت ایده را از شواهد استفاده جدا کن.
- سناریوی موفق، خطا، بازیابی و ترک فرایند را برای هر قابلیت مهم بگو.
- حداقل محصولی را پیشنهاد کن که ارزش را با کمترین هزینهٔ آزمون نشان بدهد.
- برای هر تصمیم روشن کن چه شاهد تازه‌ای باعث تغییر آن خواهد شد.
