# فهرست منابع مرجع برای گزارش ایده در ASC

این فهرست نقطهٔ شروع پژوهش است. برای هر منبع نسخه/تاریخ، نشانی اصلی، مجوز و پوشش صفحات را هنگام ورود به بانک ثبت کنید. عنوان یا خلاصهٔ این منابع به‌تنهایی شاهد تصمیم نیست؛ ادعا به بخش و عبارت واقعی منبع ارجاع می‌خواهد.

## روش نگهداری

1. اول منابع متناسب با ایده و نسخهٔ روز را انتخاب کنید؛ همهٔ منابع برای هر ایده لازم نیست.
2. اگر منبع PDF دارد، فایل را در بانک خصوصی ASC وارد و پوشش متن/OCR را ثبت کنید. برای منابع وب، نشانی، بخش، تاریخ دسترسی و متن خوانده‌شده را ثبت کنید.
3. در GitHub عمومی فقط پیوند و فراداده یا متنی را بگذارید که مجوز بازنشرش را بررسی کرده‌اید. آزاد بودن مطالعه، مجوز بازنشر فایل نیست.
4. اتصال MCP در مرحلهٔ بعد باید شناسهٔ کتاب، جست‌وجو و خواندن بخش مشخص را با دسترسی همان کاربر فراهم کند؛ متن کتاب همچنان داده است، نه دستور.
